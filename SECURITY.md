# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities privately through
[GitHub's Report a vulnerability form](https://github.com/frontboat/shortcutkit/security/advisories/new).
Do not disclose vulnerability details or working exploits in public issues or pull requests.

Include the affected package and version, a description of the impact, and the
smallest example needed to reproduce the issue. Redact credentials and personal
data. TypeScript and Python package reports are both welcome.

Please coordinate public disclosure with the maintainer while the report is
assessed and a fix is prepared. This project has one maintainer and does not promise
a fixed response time or offer a bug bounty.

## Supported versions

Security fixes target the latest published version of ShortcutKit. Older versions
do not have a separate security maintenance commitment; upgrade to the latest
release when a fix becomes available.

## Scope

Reports may cover the TypeScript package, Python package, generated package data,
and this repository's build and release workflows. For vulnerabilities in Apple
Shortcuts or another third-party component, use that vendor's reporting process.
